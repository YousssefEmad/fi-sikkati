# في سكتي — وثيقة مراجعة

| الحقل | القيمة |
| --- | --- |
| الاسم | في سكتي (Fi Sikkati) |
| النوع | مشاركة رحلات مجتمعية ومطابقة مسار |
| المجتمع الأول | مدينة العبور والمناطق القريبة، مصر |
| اللغة | عربي افتراضي (من اليمين لليسار) وإنجليزي |
| الحالة | المراحل 0–12 مبنية محلياً. الاستضافة والدومين لسه قرار تشغيل |
| الجمهور | مراجعة داخلية وعرض على جهة تمويل |

الوثيقة ثلاثة أجزاء بالترتيب: تشغيل المشروع، خطة اختبار يدوي، ثم شرح المنتج كوثيقة متطلبات.

# الجزء الأول — تشغيل المشروع

## 1. المتطلبات على الجهاز

| الأداة | الإصدار |
| --- | --- |
| Node.js | 24 |
| pnpm | 12 (`npm install -g pnpm`) |
| Python | 3.12 عبر `uv` (`python -m uv`) |
| Docker Desktop | مع Compose v2 |

## 2. أول مرة

من جذر الريبو `e:\fi-sikkati`:

```powershell
pnpm setup
```

الأمر ينسخ ملفات البيئة، يشغّل Postgres وRedis وMinIO وMailpit، يثبّت الاعتماديات، ويطبّق migrations.

لو الإعداد اتعمل قبل كده، يكفي:

```powershell
pnpm infra:up
```

على الجهاز ده Postgres منشور على المنفذ **5433** لأن 5432 مشغول. لو الاتصال رفض، راجع `POSTGRES_PORT` في `infra/compose/.env` ونفس الرقم في `apps/api/.env` داخل `DATABASE_URL` و`MIGRATION_DATABASE_URL`. استخدم `127.0.0.1` مش `localhost`.

## 3. تشغيل التطبيق

ترمينال أول، من `apps\api`:

```powershell
python -m uv run alembic upgrade head
python -m uv run uvicorn app.main:create_app --factory --reload --port 8000
```

ترمينال تاني، من جذر الريبو:

```powershell
pnpm --filter @fi-sikkati/web dev
```

الإيميلات (تأكيد الحساب وإعادة كلمة المرور) بتتبعت في الخلفية. لو عايزها تطلع فوراً، شغّل العامل من `apps\api`:

```powershell
python -m uv run arq app.workers.main.WorkerSettings
```

## 4. العناوين

| العنوان | إيه اللي هتشوفه |
| --- | --- |
| http://localhost:3000/ar | التطبيق بالعربي |
| http://localhost:3000/en | التطبيق بالإنجليزي |
| http://localhost:8025 | Mailpit — صندوق الإيميلات |
| http://localhost:8000/api/v1/docs | Swagger |
| http://localhost:8000/health/ready | جاهزية الـ API (قاعدة البيانات وRedis) |
| http://localhost:9101 | لوحة MinIO (`minio_dev` / `minio_dev_password`) |

## 5. إيقاف وإعادة ضبط

```powershell
pnpm infra:down
pnpm infra:reset
```

`infra:reset` يمسح قاعدة البيانات والملفات. بعديه لازم `alembic upgrade head` تاني.

## 6. منح الأدوار

التسجيل يعطي `PASSENGER` فقط. `ADMIN` و`SUPER_ADMIN` بيتمنحوا من SQL بعد ما الحساب يتسجل.

من أي عميل Postgres على المنفذ 5433، بقاعدة `fisikkati`:

أدمن المجتمع (أصحاب جروب الواتساب):

```sql
INSERT INTO user_roles (user_id, role)
SELECT u.id, 'ADMIN'
FROM users u
WHERE u.email = 'ايميل-الأدمن@example.com'
  AND NOT EXISTS (
    SELECT 1 FROM user_roles r
    WHERE r.user_id = u.id AND r.role = 'ADMIN'
  );
```

مالك المنصة (المطوّر فقط):

```sql
INSERT INTO user_roles (user_id, role)
SELECT u.id, 'SUPER_ADMIN'
FROM users u
WHERE u.email = 'ايميلك@example.com'
  AND NOT EXISTS (
    SELECT 1 FROM user_roles r
    WHERE r.user_id = u.id AND r.role = 'SUPER_ADMIN'
  );
```

`SUPER_ADMIN` لا يُمنح ولا يُسحب من شاشة الموقع. التفاصيل في `docs/runbooks/bootstrap-admin.md`.

# الجزء الثاني — خطة الاختبار اليدوي

اعمل حسابين على الأقل: راكب وسائق. الحساب الثالث يكون أدمن المجتمع. حسابك أنت يكون سوبر أدمن.

1. **راكب.** سجّل من `/ar/auth/register`. افتح Mailpit وانسخ رابط تأكيد الإيميل. ادخل `/me/verification` وارفع الهوية (وش، ظهر، سيلفي) وقدّم الطلب.
2. **سائق.** حساب تاني: أكّد الإيميل، وثّق الهوية، من `/drive` أضف عربية ومستنداتها وقدّم طلب السائق.
3. **مراجعة.** بحساب `ADMIN` افتح `/admin/verifications` واقبل الهوية ثم طلب السائق.
4. **رحلة.** السائق من `/trips/new` ينشر رحلة العبور → مدينة نصر، بعد ساعات، بمقاعد فاضية.
5. **بحث وطلب.** الراكب من `/search` يلاقي الرحلة ويطلب مقعد. قبل توثيق الهوية الطلب مرفوض.
6. **قبول وشات.** السائق من `/me/requests` يقبل. الراكب يفتح `/messages` ويبعت رسالة. إعادة نفس الرسالة لا تكررها. بعد إلغاء الرحلة الشات يبقى للقراءة فقط.
7. **إشعارات.** جرس الإشعارات فوق يزيد لما يوصل طلب انضمام. `/me/notifications` تعلّم الكل كمقروء.
8. **إكمال وتقييم.** قرّب ميعاد الرحلة أو عدّله في القاعدة، ابدأ الرحلة، كمّلها، قيّم الطرف التاني. المتوسط يظهر بعد 3 تقييمات.
9. **حظر.** من `/me/safety` احظر السائق. البحث وطلب المقعد يختفوا. فك الحظر يرجّعهم.
10. **أدمن المجتمع.** `/admin` يعرض الأرقام. `/admin/users` و`/admin/trips` و`/admin/reports` تشتغل. الإيميل والموبايل مش ظاهرين. تعليق حساب يشتغل.
11. **سوبر أدمن.** نفس الصفحات، ومعاها بيانات التواصل، والأدوار، والإعدادات، والفلاجز، وسجل التدقيق. فعّل الفلاج `ai.enabled`.
12. **المساعد.** `/assistant` يشرح المنتج ويقترح بحث. لا يحجز مقعد. لو الفلاج مقفول الطلب مرفوض.
13. **PWA.** من كروم على أندرويد: Add to Home Screen. من آيفون: Share ثم Add to Home Screen. الأيقونة تظهر. الحجز لا يعمل أوفلاين.
14. **صفحات العرض.** `/how-it-works` و`/safety` و`/faq` و`/about` و`/contact`، وبالإنجليزي من مبدّل اللغة.

# الجزء الثالث — شرح المنتج

## 1. الملخص

في سكتي منصة لمجتمع مدينة العبور. السائق ينشر رحلة هو رايحها أصلاً. الراكب يدور على رحلة ماشية في طريقه ويطلب مقعد. بعد القبول يتكلموا جوه الرحلة، وبعدها يقيّموا بعض.

الجملة اللي بتبيع المنتج: **لاقي ناس رايحة في سكتك.**

## 2. المشكلة

سكان العبور بيرتّبوا المشاوير في جروب واتساب برسائل زي «خارج العبور 8 الصبح لمدينة نصر». الجروب بيضيّع الرسائل، مفيش بحث بالمسار أو الوقت، مفيش مقاعد، مفيش توثيق، مفيش سجل، مفيش إبلاغ، ومفيش إدارة.

## 3. ما هو المنتج وما ليس هو

| هو | ليس هو |
| --- | --- |
| السائق ناشر رحلة موجودة | الراكب بيطلب عربية تيجي له |
| مطابقة مسار ووقت | سوق تاكسي أو أوبر |
| مساهمة مقترحة في البنزين، والكاش بين الطرفين | دفع جوه التطبيق |
| مجتمع واحد (العبور) في النسخة الحالية | تطبيق طوارئ أو تتبع حي |

لا يوجد طلب سيارة، ولا توزيع رحلات على سائقين، ولا محفظة، ولا رسائل SMS، ولا ربط بشرطة أو إسعاف.

## 4. المستخدمون

| الدور | مين | يعمل إيه |
| --- | --- | --- |
| راكب `PASSENGER` | أي حساب جديد | بحث، طلب مقعد، شات بعد القبول، تقييم، بلاغ، حظر |
| سائق `DRIVER` | بعد موافقة الأدمن على الرخصة والعربية | نشر رحلة، قبول ورفض الطلبات، بدء وإكمال وإلغاء |
| أدمن `ADMIN` | أصحاب جروب الواتساب الأصلي | طوابير التوثيق، البلاغات، المستخدمون بدون إيميل وموبايل، الرحلات، الأرقام |
| سوبر أدمن `SUPER_ADMIN` | مطوّر المنتج فقط | كل ما سبق، بالإضافة لبيانات التواصل، منح الأدوار، الإيقاف النهائي، الإعدادات، الفلاجز، سجل التدقيق |

الحساب الواحد يقدر يكون راكب وسائق مع بعض. السوبر أدمن لا يُمنح من الشاشات.

### شخصيات

| الشخصية | الاحتياج |
| --- | --- |
| سلمى، راكبة يومية من العبور لمدينة نصر الساعة 8 | تلاقي سائق موثوق من غير ما تلف في الواتساب |
| أحمد، سائق رايح وسط البلد الساعة 7:30 | يملأ مقاعد فاضية بجيران موثّقين ويقسّم البنزين |
| منى، راكبة ويكند لـ 6 أكتوبر | تعرف إذا في حد رايح الجمعة |
| عمر، أدمن المجتمع | يراجع الهويات والبلاغات من شاشة واحدة وفيها أثر |

## 5. الرحلة الأساسية

```
السائق ينشر الرحلة
    → الراكب يلاقيها بالبحث
    → يطلب مقعد
    → السائق يقبل أو يرفض
    → المقاعد تتحجز
    → الاتنين يتكلموا في شات الرحلة
    → الرحلة تبدأ ثم تكتمل
    → تقييم
```

حالات الرحلة: مسودة، منشورة، ممتلئة، قيد التنفيذ، مكتملة، ملغاة، منتهية الصلاحية.

حالات طلب المقعد: معلّق، مقبول، مرفوض، ملغى، منتهي، مكتمل.

## 6. النطاق الوظيفي

### الحساب

التسجيل بالإيميل وكلمة المرور والاسم وتاريخ الميلاد. الإيميل هو المعرّف. الموبايل اختياري وغير موثّق برسالة. السن الأدنى 18. تأكيد الإيميل، جلسات، نسيان كلمة المرور، وإغلاق الحساب بعد فترة سماح ثم إخفاء البيانات.

### التوثيق والعربية

الراكب يرفع بطاقة وش وظهر وسيلفي قبل أول طلب مقعد. السائق يضيف رخصة وعربية (رخصة السيارة وصورتها). الأدمن يراجع الطابور. الملفات خاصة ومش متاحة كرابط عام. رقم اللوحة لا يظهر للركاب.

### الرحلات والبحث

السائق يحدد النقط والوقت والمقاعد. السيرفر يحسب المسار والمساهمة المقترحة. البحث يحتاج تسجيل دخول، ويقارن نقطة الركوب والنزول بالمسار والاتجاه والوقت. النتيجة إما مطابقة لنقط التوقف أو على المسار. إحداثيات البيت الدقيقة لا تظهر إلا للسائق وللأطراف المقبولين وللأدمن. الباقي يشوف نقطة تقريبية.

### المقاعد

طلب المقعد ذرّي: مقعدين في نفس اللحظة لا يحجزوا آخر مقعد مرتين. الطلب المعلّق ينتهي عند ميعاد القيام. الإلغاء المتأخر يتحسب.

### الشات والإشعارات

كل رحلة ليها محادثة واحدة: السائق والركاب المقبولين. نص فقط. بتفتح مع النشر، والراكب يدخلها بعد القبول، وتتقفل للقراءة بعد الإلغاء وفوراً، أو بعد 24 ساعة من الاكتمال. الإشعارات جوه التطبيق، والإيميل للمهم منها. إلغاء الرحلة لا يمكن كتمه جوه التطبيق.

مشاركة الموبايل مع رفقاء الرحلة اختيارية ومقفولة افتراضياً.

### الأمان

بعد اكتمال الرحلة، كل طرف يقيّم الطرف التاني مرة واحدة خلال 14 يوم، من 1 إلى 5، مع ثلاثة أبعاد اختيارية. المتوسط يظهر بعد 3 تقييمات. لا يوجد «رقم ثقة» مركّب.

البلاغ على مستخدم أو رحلة أو رسالة. الحظر من طرف واحد وصامت: الطرفان يختفوا من بحث بعض ومن طلبات بعض ومن الشات. ثلاث بلاغات مستقلة على رسالة تخفيها.

### الإدارة

أدمن المجتمع يشغّل الطوابير والبلاغات والأرقام. سوبر أدمن يشوف بيانات التواصل وسجل كل فعل حساس. كل تعديل إداري يتسجل في audit log لا يُمسح.

### المساعد

مساعد أسئلة شائعة واقتراح بحث، خلف فلاجز `ai.enabled`. لا ينشئ حجزاً ولا يوافق على سائق ولا يغيّر بيانات. الافتراضي مقفول.

### التطبيق على الموبايل

الموقع قابل للتثبيت كأيقونة على أندرويد وآيفون. الشاشة الأساسية تتخزن. الحجز والبحث لا يشتغلوا من غير نت، ومش بنوعد بأوفلاين للمعاملات.

## 7. قواعد مختصرة

| القاعدة | المعنى |
| --- | --- |
| الهوية قبل أول انضمام | من غير توثيق مقبول لا يوجد طلب مقعد |
| السائق قبل النشر | رخصة وعربية مقبولتان |
| السعر اقتراح | المبلغ مساهمة مقترحة، والفلوس بره النظام |
| الخصوصية | عنوان البيت مش ظاهر؛ اللوحة مش ظاهرة |
| الحظر صامت | الممنوع يشوف «مش موجود» مش «أنت محظور» |
| الأدمن لا يرى التواصل | الإيميل والموبايل لسوبر أدمن فقط، والاطلاع يتسجل |
| المساعد للقراءة | يشرح ويقترح بحث، ومش بيكتب في النظام |

## 9. خارج النطاق الحالي

- تحصيل فلوس أو محفظة أو اشتراك.
- رسائل SMS أو توثيق الموبايل.
- تتبع حي للسيارة أو زر طوارئ.
- رحلات متكررة يومياً تلقائياً.
- أكتر من مجتمع في نفس التثبيت.
- غرف شات عامة للجروب كله. الشات مربوط بالرحلة فقط.
- اختيار شركة الاستضافة واسم الدومين.

## 10. الشكل التقني (للمراجع التقني)

| الطبقة | التقنية |
| --- | --- |
| الواجهة | Next.js وTypeScript وTailwind، عربي وإنجليزي |
| الـ API | FastAPI، صلاحيات في الكود مش في جدول |
| البيانات | PostgreSQL 16 مع PostGIS للمسارات |
| الطابور | Redis وarq للإيميل وتذكير الرحلات |
| الملفات | MinIO، المستندات الخاصة منفصلة عن الصور العامة |
| الإيميل المحلي | Mailpit |

جودة الـ API على الجهاز: ruff وmypy وimport-linter ناجحين، وAlembic عند المراجعة `0009`.

## 12. جملة العرض

في سكتي بتحوّل جروب واتساب العبور لمنتج: بحث بالمسار، مقاعد من غير حجز زايد، توثيق، شات مربوط بالرحلة، إبلاغ وحظر، ولوحتين إدارة — واحدة لأصحاب الجروب وواحدة لمالك المنتج.
